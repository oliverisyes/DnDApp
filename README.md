# DnDApp
> [!IMPORTANT]
> This project is still in active development, major features are still missing/non-functional.

A Windows desktop application to replace existing ttrpg character builders. <br>
Improvements on existing apps include: 
- No limit on number of characters.
- Much more customisable with easier management of rulesets and homebrewing new things.
- Runs completely locally without needing a resource intensive web browser or even an internet connection to be accessed.
- Doesn't sell your data.
- No forced updates and character data will always be available even if the app is rendered inaccessable for some reason. 

This app was built with Dungeons and Dragons in mind however if your preferred ttrpg uses similar character sheets, it may also be compatible.
